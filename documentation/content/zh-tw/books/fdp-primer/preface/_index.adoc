== 排版慣例

此表描述本書中使用的排版慣例。

[cols="1,2", frame="none", options="header"]

| 意義
| 範例

a|

|使用者輸入的內容，與螢幕上的電腦輸出對比。

....

|手冊頁面參考。
|使用 man:su[1] 來變更使用者身份。

|`$HOME` 設定為使用者的家目錄。

提示會像這樣呈現，其中包含對使用者有幫助的資訊，例如展示一種更簡單的作法。

重要資訊會像這樣呈現。
通常，這些會顯示使用者可能需要採取的額外步驟。
