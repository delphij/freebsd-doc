[[docbook-vs-asciidoc]]
== Docbook 和 AsciiDoc 的比較

這個羅塞塔石碑試圖展示 Docbook 和 AsciiDoc 之間的差異。

.Docbook 和 AsciiDoc 的比較
[cols="1,4,4"]
|===
|語言功能 |Docbook | AsciiDoc


|*粗體*
|<strong>bold</strong>
|*粗體*


|*斜體*
|<emphasis>Italic</emphasis>
|\_斜體_


|*等寬字體*
|<literal>Monospace</literal>
|`等寬字體`


|*段落*
|<para>這是一個段落</para>
|這是一個段落


|*按鍵*
|<keycap>F11</keycap>
|\kbd:[F11]


|*連結*
a|
[source,xml]
----
<link xlink:href="https://www.freebsd.org/where/">下載 FreeBSD</link>
----
a|
[source]
----
link:https://www.freebsd.org/where/[下載 FreeBSD]
----


|*區段*
a|
[source,xml]
----
  <sect1 xml:id="id">
    <title>區段 1</title>
  </sect1>
----
a|
[source]
----
 [[id]]
 = 區段 1
----


|*無序列表*
a|
[source,xml]
----
<itemizedlist>
  <listitem>
    <para>何時建立自訂核心。</para>
  </listitem>

  <listitem>
    <para>如何進行硬體清查。</para>
  </listitem>
</itemizedlist>
----
a|
[source]
----
* 何時建立自訂核心。
* 如何進行硬體清查。
----


|*有序列表*
a|
[source,xml]
----
<orderedlist>
  <listitem>
    <para>一</para>
  </listitem>
  <listitem>
    <para>二</para>
  </listitem>
  <listitem>
    <para>三</para>
  </listitem>
  <listitem>
    <para>四</para>
  </listitem>
</orderedlist>
----
a|
[source]
----
. 一
. 二
. 三
. 四
----


|*變數列表*
a|
[source,xml]
----
<variablelist>
  <varlistentry>
    <term>amd64</term>
    <listitem>
      <para>這是最常見的桌面...</para>
    </listitem>
  </varlistentry>
</variablelist>
----
a|
[source]
----
amd64::
這是最常見的桌面...
----
