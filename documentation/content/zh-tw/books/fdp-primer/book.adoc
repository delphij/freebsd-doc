摘要

感謝您成為 FreeBSD 文件計畫的一份子。您的貢獻極其寶貴，我們對此深表感謝。

本入門手冊涵蓋了開始為 FreeBSD 文件計畫（FDP）貢獻所需的詳細資訊，包括工具、軟體以及文件計畫背後的理念。

這是一份持續進行中的工作。隨時歡迎指正與補充。
