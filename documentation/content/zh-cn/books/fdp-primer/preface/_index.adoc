[[preface-conventions]]
== 排版约定

下表描述了本书中使用的排版约定。

[.informaltable]
[cols="1,2", frame="none", options="header"]
|===
| 含义
| 示例


|命令的名称。
|使用 `ls -l` 列出所有文件。

|文件的名称。
|编辑 [.filename]#.login#。

|屏幕上的计算机输出。
a|

[source,shell]
....
You have mail.
....


|用户输入的内容，与屏幕上的计算机输出形成对比。
a|

[source,shell]
....
% date +"The time is %H:%M"
The time is 09:18
....

|手册页引用。
|使用 man:su[1] 更改用户身份。

|用户和组名。
|只有 `root` 可以这样做。

|强调。
|用户 _必须_ 这样做。

|期望用户用实际文本替换的文本。
|要在手册页中搜索关键字，请输入 `man -k _keyword_`

|环境变量。
|`$HOME` 设置为用户的主目录。
|===

[[preface-notes]]
== 注释、提示、重要信息、警告和示例

注释、警告和示例出现在文本中。

[NOTE]
====
注释是这样表示的，包含需要注意的信息，因为它可能会影响用户的操作。
====

[TIP]
====

提示是这样表示的，包含对用户有帮助的信息，例如展示一种更简单的方法来完成某件事。
====

[IMPORTANT]
====
重要信息是这样表示的。
通常，这些信息会展示用户可能需要采取的额外步骤。
====

[WARNING]
====

警告是这样表示的，包含警告信息，提醒用户如果不遵守指示可能会造成损害。
这种损害可能是物理上的，对硬件或用户造成伤害，也可能是非物理上的，例如无意中删除了重要文件。
====

.一个示例
[example]
====
示例是这样表示的，通常包含展示演练或特定操作结果的示例。
====
